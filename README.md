
# 🍔 FoodieHub – Online Food Delivery System

### A Simple and Interactive Food Ordering Website

## 📌 Project Overview

FoodieHub is a simple online food delivery website developed using HTML, CSS, and JavaScript. It provides users with an easy and convenient way to explore food items and add their favourite dishes to a shopping cart.

The main objective of this project is to develop a user-friendly food ordering interface and understand the practical implementation of front-end web development technologies.

## 🎯 Objectives

- To develop a simple and attractive food ordering website.
- To provide an easy-to-use interface for customers.
- To implement shopping cart functionality using JavaScript.
- To calculate the total price of selected food items.
- To improve practical knowledge of web development.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and layout |
| JavaScript | Functionality and interactivity |

## ✨ Key Features

- **Attractive Homepage:** A clean and user-friendly website design.
- **Food Menu:** Displays different food items with their prices.
- **Add to Cart:** Users can add food items to their cart.
- **Cart Counter:** Automatically updates the number of selected items.
- **Total Price Calculation:** Calculates the total cost of selected items.
- **Interactive Interface:** JavaScript makes the website more dynamic.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your web browser.
5. Explore the website and test the cart functionality.
